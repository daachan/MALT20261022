# LT会向けインタラクティブWebスライド 企画書

## 1. プロジェクト概要
* **システム名称**: Web-based LT Presentation System
* **目的**: LT会における発表資料（スライド代わり）としての活用。聴講者の注意を引きつけ、メッセージを強力に印象づける。
* **ターゲット**: LT会の聴講者である20代の若者（エンジニア・クリエイター層など、視覚的新しさやテンポの良さを好む層）。
* **コア体験**: 従来の静的なスライド（PowerPointやKeynoteなど）の枠を超え、洗練されたミニマルな世界観と、Three.js / WebGL / p5.jsによるリッチなインタラクションが融合した「体験型プレゼンテーション」。

---

## 2. デザイン・トーン＆マナー（参考：ペンギン・キャピタル風）
* **トーン**: ミニマル、重厚感、洗練されたタイポグラフィ、ダークモード基調。
* **カラーパレット**: 黒やチャコールグレーのディープダークトーンをベースに、ソリッドな白や鋭いアクセントカラーを配置。
* **世界観**: 無機質かつスタイリッシュでありながら、スクロールやインタラクションに連動して空間がなめらかに変化する没入感のあるデザイン。デザインはこんな感じにしたいです https://www.penguin-capital.co.jp/ja

---

## 3. システムアーキテクチャ & 技術スタック
* **アーキテクチャ**: DBレス・フロントエンド完結の静的マルチページ構成（Vite + React Router想定）。
* **ホスティング**: Cloudflare Pages / Vercel（高速なCDN配信）
* **主要技術**:
  * **フレームワーク**: React / Vite (または Next.js 静的エクスポート)
  * **スタイリング**: Tailwind CSS
  * **3D / グラフィックス**: Three.js (WebGL), p5.js (インスタンスモードによるグラフ・アニメーション演出)
  * **UI / 演出**: スクロール連動エフェクト、カスタムスライド進行システム、シンタックスハイライト付きコードブロック、YouTube埋め込み対応

---

## 4. ディレクトリ構成案
Claude Codeを活用した開発を効率化するための推奨ファイル構造：

```text
my-presentation-site/
├── public/
│   ├── models/                # 3Dモデル (.glb / .gltf)
│   └── videos/                # 動画・サムネイル等
├── src/
│   ├── components/
│   │   ├── common/            # ヘッダー、ナビゲーション、共通レイアウト
│   │   ├── graphics/          # 描画系コンポーネント (ThreeCanvas.jsx, P5Sketch.jsx)
│   │   └── slide/             # スライド進行制御 (SlideDeck.jsx, CodeBlock.jsx, YouTubeEmbed.jsx)
│   ├── pages/
│   │   ├── HomePage.jsx       # トップページ（スクロール連動の全体案内・JUNNI風LP）
│   │   ├── Chapter1Page.jsx   # 1章の個別スライドページ
│   │   ├── Chapter2Page.jsx   # 2章の個別スライドページ
│   │   └── Chapter3Page.jsx   # 3章の個別スライドページ
│   ├── App.jsx                # React Routerによるルーティング定義
│   └── main.jsx
├── index.html
├── tailwind.config.js
└── vite.config.js
```

## 5. 主要機能要件
1. **トップページ（全体ハブ & LP）**:
   * 参考サイト（https://www.penguin-capital.co.jp/ja等）のような、スクロールに連動して背景のThree.jsやテキストがダイナミックに変化する演出。
   * 各章のスライドページへスムーズに遷移できるインタラクティブな導線。
2. **章ごとの個別スライドページ**:
   * URLごとに章が独立（例: `/chapter1`, `/chapter2`）。
   * キーボード操作（左右矢印キー、スペース）や画面クリックでシームレスにスライドを進行できる共通システム。
3. **リッチな表現・埋め込み**:
   * Three.jsやp5.jsを用いたインタラクティブなグラフやビジュアル演出。
   * 美しいシンタックスハイライト付きのコードブロック。
   * スムーズに再生・制御できるYouTube動画埋め込みコンポーネント。
