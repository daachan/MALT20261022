## 2. 現状のスライド構成(仮置きレイアウト・そのまま採用)

| # | スライド | 中身 | ステップ(→ 1回で1要素) |
|---|---|---|---|
| 1 | タイトル | 「メディアアートの作品に触れる」 | サブコピー「PC・スマホ・センサ…IT機器が生み出す表現を見てみよう」 |
| 2 | 作品スライド(型A) | 画像/動画の枠(左・やや傾き)+ 右下に 切り口タグ / 作品名 / 作者名・年 / 一言解説 | メディア → タグ → 作品名 → 作者・年 → 一言解説 の順に出現 |
| 3 | 作品スライド(型B) | 同じ要素の別配置(画像が左上、文字が左下〜右下) | 同上 |
| 4 | 触れる表現(デモ) | マウスで粒子が散る canvas デモ+見出し「触れる表現」 | 説明文 |
| 5 | 次へ | 「色々な作品に触れてアイデアを蓄えよう！」+「→ NEXT: INDEX に戻る」 | NEXT の案内 |

- 作品スライドは、**型A・型Bを交互に使う**想定。作品が増えたら、型の配置をコピーして枚数を増やす(1作品 = 1スライド)。
- 画像・動画の枠は仮(「IMAGE / VIDEO」の文字)。実際の素材は `public/` に置いて差し替える。YouTube 埋め込みは chapter1 の動画スライドと同じ仕組み(`data-youtube`)が使える。
- 見た目は chapter1 と共通のデザイン(案2: HUD・黒い四角の文字背景・明朝)。
