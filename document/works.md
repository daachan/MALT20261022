## 記入のルール

- **スライドに載せる項目**: 切り口 / 作品名 / 作者 / 制作年 / 一言解説 / 素材 / 出典
- **スライドに載せない項目**(発表の補足): 話す内容 / 技術・メディア / ヒートマップ上の位置 / 使用許諾・注意
- 一言解説は、1〜2行(全角40字程度まで)にするとスライドに収まる。
- 素材は、次のどれか1つ:
  - **YouTube**: URL を書く(`t=` があれば、その秒から再生)。音は「あり / なし」を書く
  - **Web サイト**: URL を書く(枠の中で操作できる。クリック後は、マウスを枠の外に出してから → で進む)
  - **画像**: `page/public/images/works/` に置き、ファイル名を書く(未実装。最初に使うときに対応)
  - **動画ファイル**: `page/public/videos/` に置き、ファイル名を書く(未実装。最初に使うときに対応)
- 出典は、スライドの右下に小さく出る(「出典: URL」)。現在は素材の URL を、そのまま出典にしている。
- ヒートマップ上の位置は、(デザイン, エンタメ, アート)の割合(合計1)。将来、ヒートマップ上のマーカーに使う予定で、今は未使用。

## 依頼の書き方(コピーして使う)

```
works.md の作品1〜8 を chapter2 に反映して。
- 空欄の項目は、今のまま(仮)で良い
- スライドの数や並びは変えない
```

- 一部だけ: 「works.md の作品3だけ chapter2 のスライド4に反映して」
- 内容を直す: works.md の該当項目を書き換えてから、「works.md の作品3を再反映して」
- 作品の順番を入れ替える: 作品の見出しの中身を入れ替えて、「順番を入れ替えたので反映して」
- 作品を増やす: 「作品9」のブロックをコピーして書き、「作品9を追加して。レイアウトは A / B の交互で」

## 現時点の注意

- **インターネット接続が前提**: YouTube と Patatap は、オフラインでは再生・表示できない(枠にその旨が出る)。

- 画像・動画ファイルの枠への差し込み(ローカル素材)は、まだ作品スライドに未実装。
- ヒートマップ上の位置の欄は、今は使わない(将来の拡張用)。記入は任意。
- 作品名・作者は、YouTube の動画タイトルとチャンネル名などから取った暫定の表記。正式な表記は、上の欄を書き換えて再反映する。
