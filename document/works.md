## 記入のルール

- **スライドに載せる項目**: 切り口 / 作品名 / 作者 / 制作年 / 一言解説 / 素材 / 出典
- **スライドに載せない項目**(発表の補足): 話す内容 / 技術・メディア / ヒートマップ上の位置 / 使用許諾・注意
- 一言解説は、1〜2行(全角40字程度まで)にするとスライドに収まる。
- 素材は、次のどれか1つ:
  - **YouTube**: URL を書く(`t=` があれば、その秒から再生)。音は「あり / なし」を書く
  - **Web サイト**: URL を書く(枠の中で操作できる。クリック後は、マウスを枠の外に出してから → で進む)
  - **画像**: `page/public/images/works/` に置き、ファイル名を書く(未実装。最初に使うときに対応)
  - **動画ファイル**: `page/public/videos/` に置き、ファイル名を書く(未実装。最初に使うときに対応)
- 出典は、スライドの右上に小さく出る(「出典: URL」)。現在は素材の URL を、そのまま出典にしている。
- **ヒートマップのピン**: 作品ごとに、アート / エンタメ / デザイン を 0.0〜1.0 で書くと、その作品のスライドのヒートマップの上に、対応する位置へピンが刺さる(→ 2回目でヒートマップが広がったあとに、上から落ちる)。
  - 3つの値の**比**が、ピンの位置を決める(合計が1でなくてもよい。値を、3つの点の重みとした平均の位置)。アート 1.0・他 0.0 → アートの点の上 / 3つ同じ値 → 3点の中央 / アートとエンタメが同じ値で、デザイン 0.0 → アートとエンタメの中間。
  - 3つとも未記入(または 0)なら、その作品のスライドには、ピンを刺さない。
  - 反映は、「works.md のピンの値を chapter2 に反映して」と依頼する。

## 依頼の書き方(コピーして使う)

```
works.md の作品1〜11 を chapter2 に反映して。
- 空欄の項目は、今のまま(仮)で良い
- スライドの数や並びは、works.md の見出しの順に合わせる
```

- 一部だけ: 「works.md の作品3だけ chapter2 のスライド4に反映して」
- 内容を直す: works.md の該当項目を書き換えてから、「works.md の作品3を再反映して」
- 作品の順番を入れ替える: 作品の見出しの中身を入れ替えて、「順番を入れ替えたので反映して」
- 作品を増やす: 「作品12」のブロックをコピーして書き、「作品12を追加して。レイアウトは A / B の交互で」

## 反映時の私の作業(参考)

1. 該当スライドの `切り口(タグ)` `作品名` `作者 ／ 制作年` `一言解説` を書き換える
2. 素材の種類に合わせて、枠の中身(YouTube / Web / 画像 / 動画)を差し替える
3. 出典を、右上に小さく表示する
4. 作品名が長い場合は、1行に収まる文字サイズへ調整する
5. 順番を変えたときは、レイアウトの A / B が交互になるよう、配置を付け直す
6. 全スライドの表示・出現順・文字の収まりを確認して、結果を報告する

## 現時点の注意

- **インターネット接続が前提**: YouTube と Patatap は、オフラインでは再生・表示できない(枠にその旨が出る)。
- 音ありの自動再生は、ブラウザの設定で止まる場合がある。止まったら P キーで再生する。
- 画像・動画ファイルの枠への差し込み(ローカル素材)は、まだ作品スライドに未実装。
- ヒートマップのピンの位置は、アート・エンタメ・デザインの値を書いたものだけに刺さる(記入は任意)。
- 作品名・作者は、YouTube の動画タイトルとチャンネル名などから取った暫定の表記。正式な表記は、上の欄を書き換えて再反映する。
